It Needs to Be Done
감정 배제 업무 지시 확인 문제

핵심 표현 · It needs to be finished by Friday. / It must be resolved. — 30문항으로 오늘 배운 수동태 지시 화법을 완전히 내 것으로 만들어 보세요.

업무 · 주어It / This error업무 그 자체
+
강도 · 조동사needs to be / must be~되어야 합니다
+
동작 · 수동p.p.(과거분사)fixed, finished…

공격적인 You must finish this!(너 꼭 끝내!) ✗  →  업무 중심 It needs to be + p.p. = 감정 제로!

오피스 예문

It needs to be submitted by end of day.오늘 일과 종료 전까지 제출되어야 합니다.

All customer inquiries should be answered within 2 hours.모든 고객 문의는 2시간 안에 답변되어야 합니다.

1. 능동 vs 수동의 뉘앙스

You have to fix this error.능동 ✗
'너 이 에러 고쳐야 해' — 개인에게 직접적 부담!
This error needs to be fixed.수동 ✓
'이 에러는 수정되어야 합니다' — 업무 중심의 객관적 전달!

2. 실무 다빈출 패턴

주어 + needs to be + p.p.패턴 A
필요성 — ~되어야 합니다(해야 해요 느낌)
주어 + should be + p.p.패턴 B
당위·권고 — ~되어야 합니다(그러는 게 좋아요 느낌)

3. 오늘의 비즈니스 꿀팁

It needs to be done by ~1등 표현
자존심을 건드리지 않고 데드라인을 명확하게 각인!
사람 탓 없이 업무 자체를 지시 글로벌 리더의 매너!

객관식 문제

25문제

유형별로 구성되어 있어요: 개념 이해 · 빈칸 채우기 · 틀린 문장 찾기 · 모두 고르기 · 단어 배열 · 대화 문제 · 뜻 고르기 · 주어·동사 찾기. 답을 고르고 채점하기를 누르면 바로 해설이 나옵니다. 한꺼번에 보려면 한번에 채점하기를, 점수와 주관식을 남기려면 완료를 누르세요.

답을 고르지 않은 문제는 오답으로 채점됩니다. 완료를 누르면 점수와 주관식 답이 내 강의실에 바로 저장됩니다.
