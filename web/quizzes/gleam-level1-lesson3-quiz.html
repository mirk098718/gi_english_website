제 03강 · I, Me, My, Mine! 인칭대명사 종결자

한 자리에 한 명!
인칭대명사 자리별 역할 확인 문제

핵심 표현 · This is mine. / Help me, please. — 30문항으로 오늘 배운 인칭대명사 4형제를 완전히 내 것으로 만들어 보세요.

주격I나는 (주어)
→
목적격me나를 · 나에게
→
소유격my나의 (+명사)
→
소유대명사mine내 것 (단독)

한국어식 This is my. ✗  →  명사 없이 말할 땐 mine! (my는 my+명사 세트)

1. 자리로 구분하는 4형제

주격 I, You, He, She, We, They (문장 맨 앞)
목적격 me, you, him, her, us, them (동사·전치사 뒤)

2. 실전 혼동 포인트

This is my phone. (my + 명사)

This phone is mine. (mine 단독)

3. 오늘의 꿀팁

영어는 대명사를 좋아해요!

Tom이라고 불렀다면 뒤엔 he · him · his로 받아주기!
