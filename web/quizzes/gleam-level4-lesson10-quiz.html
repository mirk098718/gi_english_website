We Had the Problem Fixed
사역동사 have의 외주/위탁 확인 문제

핵심 표현 · We had the system repaired. / Have it done by tomorrow. — 30문항으로 오늘 배운 스마트한 위탁 보고 화법을 완전히 내 것으로 만들어 보세요.

위탁 · 주어I / We맡기는 사람
+
사역 · 동사had / have맡겨서 처리하게 하다
+
대상 + 결과목적어 + p.p.the problem fixed

전문성 떨어지는 제가 직접 땜질했어요(I fixed it) ✗  →  전문가 위탁 I had the issue resolved = 신뢰감 보고!

오피스 예문

We had the contract reviewed by legal experts.법률 전문가에게 계약서 검토를 맡겨 완료했습니다.

Please have this report finalized by 5 PM.오후 5시까지 이 보고서가 최종 완료되도록 조치해 주세요.

1. have + 목적어 + p.p.의 의미

I had my car washed.위탁 완료
세차장에 맡겨 세차했어 — 직접 한 게 아니라 맡겨서 끝!
We had the system repaired.예문 2
시스템 수리를 맡겨서 완료했어요 — 위탁 완료 보고!

2. 업무 지시 패턴

Please have it + p.p.지시형
~가 처리되도록 조치해 주세요 — 맡겨서 끝내달라는 뜻!
Have it done by tomorrow.기한
내일까지 처리 완료되게 해 주세요.

3. 오늘의 비즈니스 꿀팁

I fixed it → I had the issue resolved.보고 격상

직접 처리 ✗ → 전문가 위탁 + 완료 보고 ✓ 스마트한 업무 보고!
