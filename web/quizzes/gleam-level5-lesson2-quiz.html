If I Were to…
미래 가정법 확인 문제

대표 표현 · If we were to accept this offer… — 30문항으로 가능성이 낮은 미래를 품격 있게 시뮬레이션하는 가정법을 완성해 보세요.

조건 · 주어If + 주어만약 ~이
+
조건 · 동사were to + 동사~한다면
↓
결과 · 주어주어 + would~할 것입니다
+
결과 · 동사동사원형~하다

조건은 were to + 동사원형, 결과는 would + 동사원형 — 빈자리에 아무 동사나 넣어 보세요!

예문

If I were to accept the offer, I would require you to join the project.그 제안을 수락한다면, 저는 당신이 프로젝트에 합류하기를 요구할 것입니다.

If we were to accept these terms, we would require a firm guarantee on delivery dates.이 조건을 수락한다면, 납기일에 대한 확고한 보증을 요구할 것입니다.

If the negotiations were to break down, what alternative would we have?협상이 결렬된다면 우리에겐 어떤 대안이 있습니까?

1. If were to의 두 얼굴

낮은 가능성 현실적으로 일어나기 힘든 미래를 가설로 시뮬레이션
극상의 정중함 상대에게 부담 없이 의견을 조심스럽게 타진

2. 귀결절 공식

would + 동사원형확신
~할 것입니다
could + 동사원형가능성
~할 수도 있습니다

3. 1강과 비교

과거 If I had known → would have p.p.
미래 If I were to → would + 원형
