제 07강 · It Has Been Changed (완료 + 수동태)

'~되어진 상태가 지금도 유효하다!'
have been + p.p. 확인 문제

핵심 표현 · The schedule has been changed. — 30문항으로 비즈니스 실무 알림 화법을 완전히 내 것으로 만들어 보세요.

현재완료have+ p.p. · 지금도 유효
+
수동태beenbe + p.p. · 되어진다
→
완료 수동태changed변경되어 있다

현재완료(have) + 수동태(been p.p.) 결합! — The schedule has been changed. (일정이 변경되어 있습니다)

1. 완료 수동태의 뉘앙스

수동태만 The meeting was postponed. → 과거의 한 번
완료 수동태 The meeting has been postponed. (연기되어 지금도 유효!)

2. 감정 빼고 프로답게

'내가 바꿨다' 대신 '~이 변경되었다'!

Your order has been shipped. / It has been approved.

The flight has been delayed due to heavy snowfall.

3. 오늘의 꿀팁 치트키

실수·민감한 공지도 완료 수동태로 부드럽게!

It has been delayed/canceled.

→ 책임을 개인에게 묻지 않고 상황만 전달
