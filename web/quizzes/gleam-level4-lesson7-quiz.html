It Has Been Decided
공식 결정 사항 공지 확인 문제

핵심 표현 · It has been decided that… / The contract has been signed. — 30문항으로 오늘 배운 완료 수동태 브리핑 화법을 완전히 내 것으로 만들어 보세요.

공지 · 주어It / The deal결정·성과 그 자체
+
완료 · 수동has/have been + p.p.~되어 왔습니다
+
내용 · 동사decided / signed결정된·체결된

개인 독단 I decided it!(내가 정했어) ✗  →  조직의 결정 It has been decided = 엄숙하고 공식적!

사내 공지 예문

It has been decided that all employees will transition to a hybrid work model.모든 직원이 하이브리드 근무 모델로 전환하기로 결정되었습니다.

All pending invoices have been processed.모든 미처리 인보이스가 정산되었습니다.

1. 완료 수동태란?

has/have been + p.p.완료 수동
'~해져 왔다' — 결과가 남은 완료 + 수동태!
The contract has been signed.예문
계약이 체결되어 왔습니다(지금 유효한 상태!).

2. 공식 공지 패턴

It has been decided that + 문장공지형
누가 결정했는지 감추고 '결정된 팩트'만 엄숙히!
Please be advised that…공문 서두
'~를 알려드립니다' — 표준 공문서 시작 멘트!

3. 오늘의 비즈니스 꿀팁

Please be advised that it has been decided to ~1등 오프닝

객관식 문제

25문제

유형별로 구성되어 있어요: 개념 이해 · 빈칸 채우기 · 틀린 문장 찾기 · 모두 고르기 · 단어 배열 · 대화 문제 · 뜻 고르기 · 주어·동사 찾기. 답을 고르고 채점하기를 누르면 바로 해설이 나옵니다. 한꺼번에 보려면 한번에 채점하기를, 점수와 주관식을 남기려면 완료를 누르세요.

답을 고르지 않은 문제는 오답으로 채점됩니다. 완료를 누르면 점수와 주관식 답이 내 강의실에 바로 저장됩니다.
