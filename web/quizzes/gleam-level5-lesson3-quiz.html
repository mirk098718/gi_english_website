If I Had Known, I Would…
혼합 가정법 확인 문제

대표 표현 · If I had studied harder, I would be… — 30문항으로 과거의 선택이 지금의 나에게 미치는 영향을 입체적으로 말해 보세요.

조건 · 주어If + 주어만약 ~이
+
조건 · 과거had + p.p.~했더라면
↓
결과 · 현재would + 동사원형지금 ~할 텐데
+
결과 · 시점now / today지금은

조건은 과거(had p.p.), 결과는 현재(would + 동사원형) — 끝에 now를 붙이면 시제 대조가 또렷해집니다!

예문

If I had studied harder, I would be a doctor now.더 열심히 공부했더라면 지금 의사가 되어 있을 텐데.

If I had backed up the project files yesterday, I wouldn't be doing all this rework today.어제 파일을 백업해 뒀더라면 오늘 이 재작업을 하고 있지 않을 텐데요.

If we hadn't invested in cloud infrastructure two years ago, we wouldn't be leading the market now.2년 전에 투자하지 않았더라면 지금 시장을 선도하지 못할 것입니다.

1. 시간축 결합

조건 과거 사실의 반대 · If + had p.p.
결과 현재 사실의 반대 · would + 동사원형

2. 순수 과거 vs 혼합

순수 과거 would have earned + back then
혼합 would be living + now

3. 10초 스피킹 꿀팁

결과절 끝에 now · today · currently를 붙이면 시제 대조가 또렷해집니다.
If I hadn't met you, I wouldn't be here today.
